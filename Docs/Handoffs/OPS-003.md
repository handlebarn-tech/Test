## Changes
- `Tools/Studio/studio.ps1`
  - New `slots` command. It lists every Unity editor that holds a DEC-013 slot: PID, worktree, branch, studio command, start time, elapsed minutes. Runs over 20 min get `OVER 20 MIN`. It writes the usual `Artifacts/Results/<stamp>-slots.json` (summary `N/2 editor slots in use; M over 20 min`). It is read-only and never kills anything.
  - `Get-UnityEditors` is the one editor filter (`*\Editor\Unity.exe`, excluding AssetImportWorker and `serve`). `Wait-UnitySlot` now calls it, so the gate and the monitor always count the same processes.
  - `Get-SlotInfo` resolves each row. The worktree and branch come from `-projectPath` (`git -C <worktree>`). The command comes from the parent's `studio.ps1 <command>`. When an agent shell runs studio.ps1, its parent command line hides the script, so the command is read from the studio log name `<stamp>-<command>.log` instead. If neither matches, the row reads `? (not studio.ps1)`, meaning the run bypassed the slot gate.
- `Tools/Studio/studio_slots_test.ps1` (new): 12 checks, no Unity needed.
  - Parent and log-name command parsing, quoted and unquoted `-projectPath`, branch lookup, the 20-min flag, and the bypass marker.
  - That `Wait-UnitySlot` uses the shared filter, and that the `slots` case contains no kill call.
- `Docs/TOOLCHAIN_EXECUTION.md`: `studio.ps1 slots` added to the command list, with a paragraph on it.
