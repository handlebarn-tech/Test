## Decisions (mine, for the lead)
- **Walkability standard:** main path ≥ 3.0 ft; reach zone ≥ 2.5 ft deep and ≥ 2 ft wide; door clear opening derived as leaf width minus ~2¼ in. These are not store facts.
- **A310 conflict:** the schedule column and the hardware-set headers disagree for doors 104/106/107. I followed the schedule column (REF-004's reading). It only changes lever vs push bar: every candidate set has a closer and a lock.
- **Restroom (103) `lock: none`:** its privacy lock is for the occupant, not a staff gate. Gameplay can model "occupied".
- **Entry `leaves: 2`:** A011 shows two 3'-0" leaves and A310 marks E101 as PAIR, so the TI settles it and it is not a GAP.
