## Key design calls
- **Intent = 6 families, each a verified golden parse** (RC-01/03/04/09/10/11) shipped as slice data. The NL parser is not needed, and the engine call is golden-checked end to end. Note: `insomnia` must use the PHRASE_MAP L16107 values (55/40), not the INTENTS key (45/35). `pain` must include the pain-functional sedation cap 55.
- **Player skill = picking the right chip** from a templated customer line, plus watching the budget. Fit is scored against the customer's *true* family through the engine (`ms / ms_top`), so a "wrong" chip with an equivalent result is not punished.
- **Budget is not an engine filter** (no `maxPrice`); it feeds `priceFit`.
- Deterministic accept/reject (threshold 50, 2 rejections → leave), for testability.
