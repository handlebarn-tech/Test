## Deliverable

2. A wireframe per screen (SVG preferred) at 1920×1080, with safe areas, font sizes and keyboard/controller focus order.
3. HUD: queue, patience, shift clock, money; minimal.
4. Accessibility: text scale, color-blind-safe status colors, reduced motion, hold-vs-toggle (spec §46).
5. UI Toolkit notes: panel/USS structure and the data field each element binds to, named as in `RECONSTRUCTION_CONTRACT.md` engine outputs.
