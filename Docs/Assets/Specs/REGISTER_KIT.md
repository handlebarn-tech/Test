- Not in this kit (owned elsewhere): POS monitor/base `PROP_POS_Terminal_A`, card terminal (DEC-086, PROC-005), scale + scale stand + acrylic panel (ART-002, REFERENCES_INDEX §2.2), deli scale (`PROP_Deli_Scale_A`).

- Counts: one kit per numbered register station (11 stations, DEC-039; register 1 is off the floor, GAP-107).

Everything else is optional per station with weights. A seeded arranger (`Tools/Blender/generators/register_arranger.py`) writes one placement JSON per station; same seed, same JSON.

**Anchors (measured, DEC-110):** counter top 34 in AFF, POS top 2'-6" deep, 4 in toe base (REFERENCES_INDEX §6.4, High); station pitch ≈ 3.2 ft (GAP-131, Low), so the TOP zone is 0.95 m wide; scale stand ≈ 1.6 × 1.3 ft, top ≈ 2.5 ft, 2 levels (§2.2, Low-Med).
