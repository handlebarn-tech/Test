# REGISTER_KIT — register workstation props, evidence spec (PROC-006, phase 1)

Source of the request: Nolan's playtest 1, "Register / Workstation Detail" (`GameFeedback10-30.txt`, DEC-096): every register gets a label printer, receipt printer, scanner, mouse, keyboard, under-counter storage (bags, boxes, personal items, cleaning supplies), a spray bottle hanging from a scale shelf, and a rag.

## Rules applied
- Facts only from: `Docs/REFERENCES_INDEX.md` §2.2 (REF-003 back-of-register stills) and §2 (camera wall tiles), `Docs/Reference/ROOM_FIXTURES.json`, DEC-021/026/039/051/062/084/086/096. No model names, brands or measured sizes are invented. Where a still does not show a fact it is a **GAP-REG-n** with candidates (DEC-047).
- **No register or counter geometry here** (World re-audits it, DEC-096 #2). Anchors name the register/operator-zone area only, **"anchor id pending ROOM_FIXTURES rev7"** (World REF-011 adds the sales-floor rows; today's graybox ids are deliberately not used).
- Excluded: cash-handling equipment (DEC-051), cameras/security hardware (DEC-031/045/062). The black low box under the keyboard at some stations (see RK-04) is **not modelled** for that reason.
- Not in this kit (owned elsewhere): POS monitor/base `PROP_POS_Terminal_A`, card terminal (DEC-086, PROC-005), scale + scale stand + acrylic panel (ART-002, REFERENCES_INDEX §2.2), deli scale (`PROP_Deli_Scale_A`).
- Quality (DEC-084): small props, LOD0 guide 5–20k tris, LOD0–LOD3 chain, 2K PBR set (BaseColor/ORM/Normal), real construction (seams, vents, cable strain reliefs, key legends as normal/albedo detail), wear. Unbranded (DEC-071): no real brand marks or model badges.
- Counts: one kit per numbered register station (11 stations, DEC-039; register 1 is off the floor, GAP-107).
