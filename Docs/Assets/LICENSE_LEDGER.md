## Repo policy derived from the licenses
- **Never commit raw third-party downloads** (Unity packages, Sonniss, Quaternius, Sketchfab archives): Quaternius QAL §3, Sonniss v2.0 and the Unity EULA all bar redistributing assets *as assets*; a public repo would breach that. Keep raws in an untracked `ThirdParty/` (gitignored) and commit only converted prefabs *if repo stays private*, plus this ledger. CC0 sources (Poly Haven, ambientCG, Kenney, BigSoundBank) are safe to commit.
- **CC BY** rows need an in-game credits entry: use the `Attribution` column text; mirror to `Docs/Assets/CREDITS.md` at import time.
- Sketchfab `CC Attribution` = CC BY 4.0 (url shown by API: creativecommons.org/licenses/by/4.0/). `CC BY-SA` (share-alike) and `Free Standard` are **rejected** by policy.
- Real-world brand/logo marks on any model (POS, ATM, packaging) must be removed/replaced at import (plan §5).
