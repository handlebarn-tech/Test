# REF-001 — Canonical reference index

**Role:** REF (Reference Analyst) · **Priority:** P0 · **Branch:** main checkout (doc-only, DEC-005)

## Goal
Index every supplied reference so ART/NPC workers can find what they need without reading everything.

## Inputs (read-only; never modify or move anything under `References/` except creating `References/Index/`)
- `References/Floor Plan.pdf`
- `References/CCTV Camera Wall.png`, `References/CCTV Camera Wall 2.png`
- `References/BAND_TFS Phoenix (NEW)_2026-09-18-21-38-18/*.jpeg` (13 eye-level store/staff photos)
- `References/LIVE_TFS_BUDTENDER_v7.11.4.md` (skim only for UI look)
- `Docs/ASSET_PRODUCTION_PLAN.md` — only room-list / Bill-of-Assets headings, to align room names.

## Owns (writes only these)
- `Docs/REFERENCES_INDEX.md`
- `References/Index/` (new; derived files only: plan PNG, crops, contact sheets)
- Append to `Docs/KNOWN_GAPS.md` (GAP-1xx range)

## Deliverable
1. Floor plan: room list with names as printed, printed dimensions/scale, doors/openings, counters/registers. State the scale basis and confidence. Rasterize the plan to PNG under `References/Index/` (PyMuPDF or any free tool).
2. CCTV: per-camera table (tile #, room/zone, key fixtures, mapped plan room, confidence).
3. BAND photos: per-photo table (room/zone, fixtures, materials/finishes, clutter, signage, human-scale cues, staff attire/vibe). Describe attire/role only — no personal identification of staff.
4. Room × source coverage matrix (plan / CCTV / photo), blind rooms flagged.
5. Scale cues usable for graybox (door widths, counter heights, ceiling grid) with method + confidence.
6. KNOWN_GAPS entries for every unresolved item.

## Rules
Do not invent dimensions; estimates are labelled with method. No personal data about staff.

## Validation
Every reference file appears in the index; every plan room appears in the coverage matrix.

## Handoff
`Docs/Handoffs/REF-001.md` (≤40 lines): outputs, confidence summary, top gaps, what ART-001 needs to know.
