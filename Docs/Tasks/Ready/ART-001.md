# ART-001 — Measured graybox (+ QA-001 capture/test harness)

**Role:** ART-ENV + QA (one Unity session) · **Priority:** P0 · **Branch:** `task/ART-001` worktree off `main` after REVIEW-W1 merges

## Goal
A walkable, floor-plan-accurate graybox of the whole building in Unity, plus the harness that proves it with screenshots.

## Read
`Docs/Handoffs/REF-001.md`, `Docs/REFERENCES_INDEX.md` §1 (rooms, openings, fixtures, coordinates), `Docs/KNOWN_GAPS.md` GAP-1xx, `Docs/TOOLCHAIN_EXECUTION.md` §12, §17–18, `Docs/Handoffs/BUILD-001.md`.

## Owns
- `UnityProject/Assets/_Game/Art/Graybox/`
- The Retail / BackRooms / Hub / Exterior scene contents
- `Assets/_Game/Code/Editor/Graybox/`
- `Assets/_Game/Code/Tests/PlayMode/`
- New `studio.ps1` commands `unity-test-play` and `unity-capture`
- `Docs/Assets/Specs/GRAYBOX.md`

## Deliverable
1. **Data-driven graybox generator.** Put room shells, openings and major fixtures in a data file (JSON) transcribed from REFERENCES_INDEX. An editor script builds walls, floors and openings from it, rebuildable in batchmode.
   - Use the REF-001 mapping: X = x·0.3048, Z = −y·0.3048.
   - Placeholder heights carry their GAP id in the object name or data.
   - Doors are 3'-0"×7'-0" by convention.
2. **Fixtures:** blockouts for counters, registers, deli/jar walls, shelving and HUB racks, each tagged with confidence.
3. **Reference cameras:** one per mapped CCTV tile, approximate pose.
4. **Simple test player:** capsule, first-person, Input System, so the graybox can be walked.
5. **QA harness:**
   - `unity-capture` renders each reference camera to `Artifacts/Screenshots/`.
   - `unity-test-play` runs PlayMode tests.
   - Add one PlayMode test: the player spawns in Retail, can reach BOH through doors, and doesn't fall through the floor.

## Validation
- compile, edit tests and play tests all pass.
- Capture contact sheet produced.
- Overlay check: a top-down orthographic capture compared against `References/Index/floor_plan_grid_1ft.png`; record the max deviation in GRAYBOX.md.
